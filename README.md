### `anchr/`

Personal knowledge retrieval system.

```text
upload
  ↓
parse
  ↓
normalize
  ↓
chunk
  ↓
embed
  ↓
index
  ↓
retrieve
  ↓

  ↓
```

Not just a chatbot with a vector database.

The goal is to build the whole path from **document → retrieval → context → answer**.

