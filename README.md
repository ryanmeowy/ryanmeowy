## Featured project — Anchr

> **An evidence-first workspace for knowledge grounded in your own documents.**

Most RAG demos stop at "the model produced text." Anchr is built around the harder question:
*where did that come from, and was it actually in the document?*

It is self-hostable, does hybrid search over your own documents, answers with citations that
resolve to a real source passage, and runs multi-step agentic reading when a single retrieval
pass is not enough.

| Repository | What it does | Stack |
| --- | --- | --- |
| **[anchr-app](https://github.com/ryanmeowy/anchr-app)** | Knowledge management, hybrid retrieval, cited answers, agent runs | Java · Spring Boot · Spring AI · Elasticsearch |
| **[anchr-web](https://github.com/ryanmeowy/anchr-web)** | The browser workspace: knowledge bases, source preview, agent activity | Next.js · React · Tailwind CSS |
| **[anchr-docling](https://github.com/ryanmeowy/anchr-docling)** | Turns PDFs and office documents into retrievable content | Python · Docling · FastAPI |
| **[anchr-eval](https://github.com/ryanmeowy/anchr-eval)** | Reproducible offline evaluation with evidence binding | Python |
